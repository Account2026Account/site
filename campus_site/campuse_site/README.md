# Campus

## Установка
Положите **всю папку** целиком (app.py, services/, templates/, static/, config.py …).

Если используете старый путь `campuse_site/campuse_site/campus/`, скопируйте туда:
- `app.py`, `config.py`, `_schemas.py`, `db.py`
- папку `services/`
- `templates/` и `static/` рядом с `app.py` (или поправьте пути в начале app.py)

```bash
pip install -r requirements.txt
python app.py
```
Логин: `admin` / `admin123`

## Новое в этой версии
- **Группы** — карточки вместо таблицы (кнопка × больше не наезжает на селекты)
- **Куратор** — один бейдж с числом групп (не дублируется)
- **Подсказки** в журнале и итоговых: как ставить посещаемость (1/0/2), оценки, диф. зачёт
- **Excel-шаблон**: лист «Инструкция», колонки с доп. баллами, лист «Итоги»
- **Загрузка Excel** — крупная кнопка и область выбора файла
- **Итоговые оценки** — оформление как у журнала, поиск студента
- **Поиск** в админке (люди, предметы, назначения), у преподавателя, в диспетчере, в итогах
- **Резервная копия** `/admin/backup`
