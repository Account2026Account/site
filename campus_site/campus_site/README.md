# Campus — журнал, расписание и задания

## Запуск

```bash
cd campus
pip install -r requirements.txt
python app.py
```

http://127.0.0.1:5000

**admin** / `admin123`  
**dispatcher** / `dispatcher123`

При первом запуске — только админ и диспетчер. Преподавателей, студентов, назначения и **доступ к журналам** настраиваете в **/admin**.

## Что нового

### Доступ к журналам
- Отдельная таблица прав: редактирование / только просмотр.
- В админке вкладка **«Доступ к журналам»**.
- При назначении преподавателя на предмет доступ «редактирование» выдаётся автоматически.
- Клик «Журнал →» из расписания тоже выдаёт доступ (больше нет 404).

### Уведомления
- Колокольчик 🔔 в шапке и страница **/notifications**.
- Уведомления при: новой оценке, новом задании, объявлении.

### Мобильный интерфейс
- Удобное меню, крупные кнопки, адаптивные таблицы и формы.

### Прокрутка
- После сохранения в админке / диспетчере страница возвращается к той же позиции прокрутки (не прыгает наверх).

## Учётные записи
Только служебные: admin и dispatcher. Остальное создаётся через админку.
