# Campus — журнал посещаемости и оценок

## Запуск
```bash
cd campus   # или из корня, где campus/app.py
pip install -r ../requirements.txt
python app.py
```
Откройте http://127.0.0.1:5000  
Логин по умолчанию: `admin` / `admin123`

## Новое в этой версии
- **Уважительная причина** отсутствия: кнопка «Уваж. причина» в журнале + поле причины («у» в ячейке)
- **Excel**: цвета оценок/пропусков/уваж., колонки уваж. и доп. баллов
- **Доп. баллы**: сворачиваемый блок условий (анимация)
- **Итоговые оценки**: диф. зачёт (зима), промежуточная аттестация, экзамен (лето) — даты, таблица, Excel
- **Уведомления**: кнопка «Стереть историю»
- **Админ → Сервис**: очистка оценок группы/студента, личные объявления + уведомление
- Улучшенный стиль раздела заданий
